# Bahraini-Food-Detection

It's Bahraini food classification streamlit app where food is detected and classified into dishes 

technologies used: Roboflow ,ultralytics, VS code, matplotlib.pyplot, IPython.display, streamlit, etc.

workflow:
1-collecting and augmenting data (Images) using roboflow
2-train the model in VS code
3-evaluating the perfomance of the model
4-conducting comparison analysis using confusion metrix
5-deploying model into streamlit
6-building streamlit app that applies the model with interactively
